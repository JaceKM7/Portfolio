# Jace Mixon Portfolio

A static portfolio website featuring selected projects, professional experience, and a downloadable resume.

## Local preview

Open `index.html` in a browser, or serve the repository with any static-file server.

## GitHub Pages deployment

The included workflow deploys every push to `main`. In the repository settings, set **Pages** → **Build and deployment** → **Source** to **GitHub Actions**. The resume PDF is deployed alongside the site and is available from the site’s resume links.
